## 4. النقاش التجاري (التسعير)
| الاقتراح | صاحبه | رد الفريق |
|---|---|---|
| شهرين + **350$** + دعم 18 شهر، قابل للتفاوض | عبدالكريم | معين: "ضروري نحبك السعر بدقة" لأن العميل يبيع 5000/يوم |
| **80,000 ريال يمني** | هلال | مازن: "مناسب" |
| **50–100 ريال من كل فاتورة** | عمار | هلال: "شريك أنت" — مازن: "صفقة رابحة لنا خاسرة له، لا يجوز" — **مرفوض** |
| سعر ثابت + **رسوم تحديث سنوية** (نموذج الشركات) | مازن | مقبول مبدئياً |
| ابدأ بـ 200–250 ثم تفاوض | مازن | — |
| **دفعة مقدمة 30%** لاختبار الجدية | معين | — |

**الخلاصة:** الفريق يميل لسعر ملكية ثابت (نطاق 250–350$ أو ما يعادله بالريال) + مقدم + دعم محدد + تحديثات سنوية اختيارية. السعر النهائي **مفتوح** (Q9).

## 5. المخاوف والملاحظات النقدية (للتعلم)
| الملاحظة | التحليل |
|---|---|
| "حددوا لي وأنا بخلي 20 مبرمج بأقوى الموديلات يشتغلوه الليلة كامل" | ⚠️ خطر: سرعة بدون هيكل تناقض هدف "مؤسسة/قابل للتطوير". الحل: الأرصدة تُستثمر في تحليل وتصميم وسكافولد منظم، ثم تنفيذ Module-by-Module باختبارات. |
| هلال: "ضروري نعرف طلبات الزبون... اشتغلت افتراضات" | ✅ صحيح. المرحلة 0 (تأكيد المتطلبات) إلزامية قبل الكود. |
| هلال: "كل واحد يسوي توثيق مبدئي ثم تحليل شامل يأخذ الحسن من كل تحليل" | ✅ منهجية صحيحة — هذا المستودع هو تنفيذها. |
| مازن: "اشتغلت البيانات والهيكلة" + "وثيقة صارمة لـ AI Coding Agent" | ✅ يُدمج في ENGINEERING-RULES و ADRs. |
| منصور: "المخزون شغلته شغلة قوية" | ✅ أهم ملاحظة واقعية — تقود تصميم Lots + Ledger. |
| تعدد الآراء بدون مرجع | الحل: SRS واحد معتمد + DECISIONS-LOG. |
