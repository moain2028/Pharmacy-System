# R4 — سياق السوق اليمني وأثره على التصميم

> **الهدف:** تحويل واقع التشغيل في اليمن إلى متطلبات غير وظيفية وقرارات تصميم ملموسة. كل بند: الواقع → الأثر → القرار التصميمي.

---

## 1. البنية التحتية

| الواقع | الأثر على النظام | القرار التصميمي |
|---|---|---|
| **انقطاع الكهرباء** متكرر وطويل؛ الاعتماد على مولدات/طاقة شمسية/بطاريات | إغلاق مفاجئ للجهاز أثناء عملية بيع → خطر فساد بيانات | ✅ قاعدة بيانات ACID (PostgreSQL/SQLite WAL) · كل عملية بيع في Transaction واحدة · حفظ مسودة الفاتورة محلياً كل تغيير · استئناف تلقائي بعد إعادة التشغيل · UPS موصى به في دليل التركيب |
| **إنترنت ضعيف/متقطع/مكلف**؛ انقطاعات وطنية سابقة عطّلت البنوك والصرافة (World Bank 2020) [1] | أي اعتماد على السحابة = توقف الصيدلية | ✅ **Offline-first إلزامي**: كل الوظائف تعمل محلياً 100% · السحابة اختيارية (نسخ احتياطي، تقارير للمالك، مزامنة فروع) |
| أجهزة متواضعة (Windows 7/10، 4GB RAM شائع) | تطبيقات ثقيلة (Electron 300MB RAM، Odoo) لا تناسب | ✅ تطبيق خفيف: Tauri (~5–10MB، ~50–80MB RAM) أو متصفح · دعم Windows 10+ أساسي، Windows 7 عبر المتصفح فقط |
| طابعات حرارية رخيصة (80mm/58mm، ESC/POS، USB) وقارئات باركود USB (HID) | الطباعة العربية على الحرارية مشكلة شهيرة (ترميز) | ✅ طباعة كصورة (Raster) عبر ESC/POS لضمان العربية · قالب 80mm و58mm · قارئ HID كلوحة مفاتيح |

## 2. النقد والعملات

| الواقع | الأثر | القرار |
|---|---|---|
| **عملتان فعلياً**: ريال يمني بسعرين مختلفين (مناطق صنعاء ~534/USD vs عدن ~1,616/USD — أكتوبر 2025) [2][3] + تداول واسع للريال السعودي والدولار | السعر قد يُحدد بالسعودي ويُحصّل بالريال بسعر يومي | ✅ **Multi-currency من التصميم**: عملة أساسية للدفاتر (YER) · أسعار يمكن تخزينها بعملة ثانية · سعر صرف يومي يدوي (لا API موثوق) · الفاتورة تعرض المبلغ بالعملتين · فرق العملة يُسجل محاسبياً |
| تقلبات حادة (الريال فقد ثم استعاد 44% في 2025) [4] | تكلفة الشراء القديمة لا تعكس إعادة الشراء | ✅ تكلفة لكل دفعة (Specific Identification) + تقرير "سعر إعادة الشراء" · إمكانية تحديث سعر البيع جماعياً بنسبة |
| **نقص السيولة النقدية** وقيود على التحويل [5] | البيع الآجل والدفع الجزئي شائع | ✅ ذمم عملاء/موردين + دفعات جزئية + كشف حساب |
| لا بوابات دفع إلكترونية منتشرة؛ محافظ محلية (جوالي، فلوسك، كاش...) ناشئة | الدفع نقدي أساساً | ✅ طرق دفع قابلة للتهيئة (نقد، محفظة X، تحويل) بدون تكامل إلزامي · تكامل لاحق |
| عدم استقرار الجهات الضريبية/الزكاة؛ لا فوترة إلكترونية إلزامية | لا متطلب امتثال رسمي الآن | ✅ تصميم يسمح بإضافة ضريبة/QR لاحقاً (مثل ZATCA السعودية إن توسعنا للخليج) |

## 3. خصوصيات الأدوية في اليمن

| الواقع | الأثر | القرار |
|---|---|---|
| **أدوية "مهرّبة"/موازية** بنفس الصنف لكن بسعر وتاريخ مختلف (ملاحظة منصور) | نفس الصنف بتكاليف متعددة ومصادر متعددة | ✅ **Lot** لكل استلام بسعر تكلفة خاص + حقل `source_type` (رسمي/موازي) + مورد الدفعة · تقرير ربحية لكل دفعة |
| البيع **بالحبة والشريط والعلبة** شائع جداً (قدرة شرائية منخفضة) | وحدات هرمية إلزامية | ✅ هرمية وحدات بمعاملات (علبة=3 شرائط، شريط=10 حبات) · المخزون بأصغر وحدة (SSU) · سعر لكل وحدة |
| قاعدة بيانات أدوية وطنية غير متاحة رقمياً بشكل موثوق (الهيئة العليا للأدوية) | لا قاعدة جاهزة رسمية | ✅ استيراد Excel من العميل + قاعدة أولية نبنيها تدريجياً (الاسم العلمي/التجاري/الشركة) · لاحقاً: قاعدة مشتركة بين عملائنا |
| الاسم العلمي مهم للبدائل (نقص توريد متكرر) | البحث بالاسم العلمي واقتراح بدائل | ✅ حقل `generic_name` + شاشة "بدائل متوفرة" في POS |
| باركود EAN-13 على أغلب العلب، DataMatrix نادر | قارئ عادي يكفي الآن | ✅ EAN-13 أساسي + محلل GS1 AI جاهز للمستقبل |

## 4. العنصر البشري

| الواقع | الأثر | القرار |
|---|---|---|
| موظفو الصيدليات غالباً بخبرة حاسوبية محدودة؛ دوران عالٍ | التدريب مكلف؛ الواجهة يجب أن تُتعلم في ساعة | ✅ شاشة بيع واحدة بسيطة · اختصارات واضحة · رسائل عربية بسيطة · فيديوهات تدريب قصيرة · وضع "مبتدئ" يخفي المتقدم |
| **عدم ثقة المالك بالموظفين** (ملاحظة منصور: البائع لا يعدل) | الرقابة أهم من المرونة | ✅ لا تعديل بعد الترحيل · كل تجاوز بصلاحية وسبب · سجل تدقيق · تقرير "نشاط الموظف" للمالك · إغلاق وردية (Shift) بمطابقة الصندوق |
| المالك غالباً غير متواجد؛ يريد متابعة من جواله | — | ✅ (MVP+1) تطبيق/صفحة مالك للقراءة فقط عبر مزامنة اختيارية أو تقرير يومي عبر واتساب/تلغرام |
| لغة عربية فقط لأغلب المستخدمين؛ بعض الأسماء التجارية إنجليزية | — | ✅ RTL أصلي · بحث يتسامح مع العربية/الإنجليزية/الأخطاء الإملائية (pg_trgm) |

| **القرصنة ونسخ البرامج** شائعة جداً | خسارة إيرادات؛ طلب معين الصريح | ✅ ترخيص Ed25519 مرتبط بالجهاز + Grace offline — docs/06-security/LICENSING.md |

| منافسون محليون راسخون (يمن سوفت) لكن للكبار | — | ✅ نستهدف الشريحة الصغيرة/المتوسطة المهمَلة ثم نصعد |
