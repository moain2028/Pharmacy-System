# الأمن (Security) — نموذج التهديدات + OWASP ASVS L2 + RBAC

> **المعايير:** OWASP ASVS 4.0 Level 2 (تطبيق يتعامل مع بيانات مالية)، OWASP Top 10 2021، مبادئ ISO 27001. الترخيص في `LICENSING.md`.

---

## 1. نموذج التهديدات (STRIDE مبسّط)
| التهديد | السيناريو في الصيدلية | الدفاع |
|---|---|---|
| **Spoofing** | كاشير يستخدم حساب زميله لتمرير خصم/مرتجع | كلمة مرور + PIN شخصي، قفل تلقائي بعد خمول، سجل تدقيق بالجهاز |
| **Tampering** | تعديل فاتورة بعد الطباعة؛ تعديل قاعدة البيانات مباشرة | Immutable ledgers (DB triggers)، المستندات المرحّلة محمية، checksum للنسخ، صلاحيات ملف DB |
| **Repudiation** | "ما أنا اللي سويت المرتجع" | `audit_log` لكل فعل بالمستخدم والجهاز والوقت؛ الترحيل يحمل `posted_by` |
| **Information Disclosure** | موظف يرى أرباح المالك؛ سرقة نسخة احتياطية | RBAC دقيق (الكاشير لا يرى التقارير المالية)، تشفير النسخ AES-256-GCM، لا أسعار تكلفة في شاشة الكاشير |
| **Denial of Service** | انقطاع كهرباء/نت؛ قاعدة بيانات تالفة | Offline-first، WAL/fsync، نسخ يومية، استعادة بخطوة |
| **Elevation of Privilege** | كاشير يمنح نفسه صلاحيات | إدارة الأدوار للمالك فقط؛ Guards في API؛ لا ثقة بالواجهة |
| **Piracy** | نسخ البرنامج لصيدلية أخرى | الترخيص (LICENSING.md) |
| **Insider (المالك نفسه)** | إخفاء مبيعات من المحاسب/الشريك | خارج نطاقنا تقنياً؛ Immutable ledgers تجعل الإخفاء يتطلب حذف الكل (ملاحظ) |

## 2. المصادقة (ASVS V2)
| البند | التنفيذ |
|---|---|
| تخزين كلمات المرور | **Argon2id** (m=64MB, t=3, p=4, salt 16B) |
| سياسة كلمة المرور | ≥ 8 أحرف؛ فحص ضد قائمة شائعة؛ لا تعقيد إلزامي مُرهق (NIST 800-63B) |
| PIN سريع للكاشير | 4–6 أرقام، Argon2id، صالح فقط لتبديل المستخدم على جهاز مُسجّل دخول بالفعل، قفل بعد 5 محاولات |
| الجلسات | JWT access **15 دقيقة** (HS256/EdDSA بمفتاح محلي يُولَّد عند التثبيت) + refresh token 12 ساعة (httpOnly cookie للويب / Tauri secure store) مع rotation |
| قفل الحساب | 5 محاولات فاشلة → قفل 15 دقيقة؛ المالك يفك القفل |
| خمول | قفل شاشة POS بعد N دقيقة (قابل للتهيئة) يتطلب PIN |
| إعادة تعيين | المالك فقط؛ لا بريد (أوفلاين) |
| حساب المالك الأول | يُنشأ عند التثبيت؛ **كلمة استرداد** تُطبع وتُحفظ (لاستعادة الوصول بدون إنترنت) |

## 4. حماية الإدخال والإخراج (ASVS V5)
- Zod على كل DTO؛ رفض الحقول غير المعروفة.
- Prisma/معاملات فقط (لا SQL نصي بمدخلات).
- CSP صارم للـ SPA؛ Helmet؛ تعقيم HTML في قوالب الفاتورة (المالك يعدّل القالب → sanitize).
- حدود حجم الطلبات؛ Rate limiting على `/auth/*`.

## 5. حماية البيانات (ASVS V6, V8)
| البند | التنفيذ |
|---|---|
| قاعدة البيانات المحلية | ملفات بصلاحيات مستخدم الخدمة فقط؛ كلمة مرور DB عشوائية تُولَّد عند التثبيت وتُخزَّن في Windows Credential Manager / Tauri store |
| النسخ الاحتياطية | AES-256-GCM؛ المفتاح مشتق من عبارة مرور المالك (Argon2id) + ملف مفتاح؛ SHA-256 checksum |
| أسرار التطبيق | `.env` خارج المستودع؛ gitleaks في CI |
| سجلات | بلا كلمات مرور/توكنات؛ تنقيح PII في الـ diagnostic bundle |
| حذف البيانات | لا حذف فعلي للمستندات؛ تصدير كامل متاح للمالك دائماً |

## 6. الاتصالات (ASVS V9)
- محلياً: `localhost` أو LAN؛ HTTPS ذاتي التوقيع اختياري للـ LAN (أداة إعداد تولّد شهادة).
- خارجياً (ترخيص/نسخ سحابي): TLS 1.2+ فقط؛ Certificate pinning لخادم الترخيص (اختياري).

## 7. التدقيق والسجلات (ASVS V7)
- `audit_log` append-only؛ يشمل: تسجيل دخول/خروج/فشل، تغييرات الأصناف/الأسعار/المستخدمين/الإعدادات، كل override/approval، فتح/إقفال وردية، النسخ/الاستعادة، تغيير الترخيص.
- المالك يملك شاشة تدقيق بفلاتر وتصدير.

## 8. سلسلة التوريد والبناء (ASVS V14)
- `pnpm audit` + Dependabot/Renovate؛ lockfile ملتزم.
- توقيع إصدارات Tauri (Updater يتحقق من التوقيع).
- SBOM (CycloneDX) مع كل إصدار.
- CI على GitHub Actions بأذونات دنيا.

## 9. قائمة تحقق ASVS L2 مختصرة (قبل كل إصدار رئيسي)
- [ ] V2 المصادقة: Argon2id، قفل، جلسات قصيرة، rotation
- [ ] V3 الجلسات: إبطال عند تغيير كلمة المرور/الدور
- [ ] V4 التفويض: كل endpoint خلف Guards؛ اختبارات سلبية (كاشير يحاول مرتجع → 403)
- [ ] V5 الإدخال: Zod شامل؛ لا SQL نصي
- [ ] V6 التشفير: AES-GCM للنسخ؛ مفاتيح خارج الكود
- [ ] V7 السجلات: لا أسرار؛ audit كامل
- [ ] V8 البيانات: صلاحيات ملفات؛ تصدير آمن
- [ ] V9 الاتصالات: TLS للخارج
- [ ] V12 الملفات: التحقق من نوع/حجم الاستيراد (CSV/XLSX)؛ لا تنفيذ
- [ ] V13 API: OpenAPI، أخطاء موحدة بلا تسريب
- [ ] V14 التهيئة: Helmet/CSP؛ تبعيات محدثة؛ SBOM
