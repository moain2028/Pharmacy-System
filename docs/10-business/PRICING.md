# التسعير ونموذج الإيراد (Pricing & Revenue Model)

> **المدخلات:** نقاش الفريق (350$ عبدالكريم · 80,000 ريال هلال · نسبة/فاتورة عمار (مرفوض) · سعر ثابت + تحديثات سنوية مازن · مقدم 30% معين)، واقع السوق (R4)، المنافسون (R1).
> **الحالة:** مقترح للتصويت (P-003).

---

## 1. حقائق تحكم التسعير
| الحقيقة | الأثر |
|---|---|
| العميل يبيع 5,000–11,000 ريال/يوم. في مناطق صنعاء (~534 ريال/$) هذا ≈ **9–20$/يوم** → ~400–600$/شهر مبيعات؛ في مناطق عدن (~1,616 ريال/$) ≈ **3–7$/يوم** → ~100–200$/شهر | 350$ = شهر مبيعات كاملة (صنعاء) أو 2–3 أشهر (عدن). **السعر يجب أن يُقاس بالريال وبمنطقة العميل.** |
| يرفض الاشتراك | الملكية أساسية؛ الاشتراك خيار ثانٍ |
| المنافسون المحليون للصغار (بديل سوفت وأمثاله) يبيعون بنطاق تقديري 50,000–150,000 ريال + دعم | نحن أعلى قيمة (ميزات حديثة) لكن لا نستطيع تجاوز السقف النفسي كثيراً في الصفقة الأولى |
| العميل الأول = **Reference Customer** (مرجع تسويقي + تجربة حقيقية) | نقبل هامشاً أقل مقابل شهادة وملاحظات |
| تكلفتنا الفعلية للـ MVP ≈ 70 يوم عمل (ROADMAP) | لا يمكن تغطيتها من عميل واحد — **المنتج يُستهلك على عشرات العملاء**؛ العميل الأول يدفع "رخصة" لا "تطوير" |

## 2. نماذج الإيراد المقترحة

### النموذج A — ملكية دائمة (Perpetual) + دعم/تحديثات سنوية ✅ الأساسي
| البند | Starter | Pro | Enterprise |
|---|---|---|---|
| رخصة دائمة (جهاز واحد / 3 أجهزة / غير محدود) | **200$** | **350$** | من 800$ |
| يشمل: تركيب + إدخال أصناف أولي (حتى 500 صنف من Excel) + تدريب 2 ساعة + دعم **12 شهراً** + تحديثات 12 شهراً | ✅ | ✅ | ✅ + زيارة شهرية |
| تجديد الدعم والتحديثات (اختياري بعد السنة) | 60$/سنة | 90$/سنة | 20% من الرخصة |
| جهاز إضافي | 50$ | 50$ | — |
| ميزة إضافية (عملات، مواقع، نسخ سحابي) | 30–50$ لكل ميزة | مشمولة | مشمولة |
| **الدفع:** 50% عند التوقيع، 50% عند Go-live | | | |

> **بالريال اليمني:** يُسعَّر بالدولار ويُحصَّل بالريال بسعر يوم الدفع (حماية من التقلب) — أو يُثبَّت بالريال في العقد مع بند مراجعة إن تجاوز التقلب 15%.

### النموذج B — اشتراك (لمن يفضّله)
| | Starter | Pro |
|---|---|---|
| شهري | 15$ | 25$ |
| سنوي (شهران مجاناً) | 150$ | 250$ |
| يشمل كل التحديثات والدعم والنسخ السحابي | ✅ | ✅ |
| بعد التوقف: قراءة فقط + تصدير | ✅ | ✅ |

### النموذج C — نسبة من كل فاتورة ❌ مرفوض
أسباب الفريق صحيحة: التاجر يرفض الشراكة في إيراده؛ يُشعره بالمراقبة؛ تحصيل معقد. **لا يُعرض.**

## 3. العرض المقترح للعميل الأول (Reference Deal)
| البند | القيمة |
|---|---|
| الباقة | **Pro** (3 أجهزة، كل الميزات الأساسية) |
| السعر | **سعر Starter: 200$** (أو ما يعادله بالريال) — خصم "العميل المرجعي" 43% |
| يشمل | تركيب، إدخال الأصناف من Excel، تدريب، دعم وتحديثات **18 شهراً** (بدل 12 — كما عرض عبدالكريم) |
| المقدم | **50% (100$)** عند التوقيع — يختبر الجدية (معين) ويغطي جزءاً من التكلفة |
| الباقي | عند التشغيل الفعلي (Go-live) |
| مقابل | شهادة/فيديو مرجعي + السماح بزيارة عملاء محتملين + ملاحظات UAT |
| التجديد بعد 18 شهراً | 60$/سنة اختياري |
| إن طلب تخصيصاً خارج النطاق | 15$/ساعة أو تقدير ثابت |

**لماذا 200$ وليس 350$ أو 80,000 ريال؟**
- 80,000 ريال ≈ 50$ (عدن) أو 150$ (صنعاء) — أقل من قيمة المنتج ويضع سقفاً منخفضاً للعملاء التاليين.
- 350$ هو سعر Pro الحقيقي — نُبقيه **معلناً** في العرض مع خصم مرجعي واضح، فيبقى السعر المرجعي للسوق 350$ ويشعر العميل بالقيمة.
- 200$ ≈ 107,000 ريال (صنعاء) أو 323,000 (عدن) — **يجب التحقق من منطقة العميل**؛ إن كان في منطقة 1,616 فالسعر المعادل قد يحتاج تخفيضاً أو تقسيطاً (3 دفعات).

## 4. اقتصاديات الوحدة (Unit Economics) — تقديري
| البند | القيمة |
|---|---|
| تكلفة اكتساب عميل (زيارة + عرض + تركيب + تدريب) | ~4–6 ساعات ≈ 40–60$ |
| تكلفة الدعم السنوي لكل عميل | ~3–5 ساعات ≈ 30–50$ |
| هامش الرخصة (Starter 200$) | ~100–120$ بعد الاكتساب والدعم الأول |
| نقطة التعادل لتكلفة MVP (~70 يوم ≈ 3,500–5,000$ بتسعير داخلي) | **~30–40 عميلاً** Starter/Pro أو ~15 Pro + تجديدات |
| هدف السنة الأولى | 25–40 صيدلية (اليمن) → 6,000–10,000$ + تجديدات متكررة |
| القيمة الحقيقية | قاعدة عملاء للانتقال إلى SaaS/الخليج بسعر 25–50$/شهر |

## 5. نقاط التفاوض (Talking Points) مع العميل
1. **"ما في اشتراك"** — تملك النظام للأبد؛ التحديثات اختيارية.
2. **"يشتغل بدون نت وبدون كهرباء مستقرة"** — ما يوقف بيعك.
3. **"كل دفعة بتاريخها وسعرها"** — تعرف ربحك الحقيقي وتتفادى المنتهي (كم خسرت السنة الماضية من المنتهي؟).
4. **"الموظف ما يقدر يعدل فاتورة بعد ما يطبعها"** — حمايتك.
5. **"نسخة احتياطية تلقائية مشفرة"** — بياناتك ما تضيع.
6. **"واجهة عربية حديثة تشتغل على أي جهاز"** — الكاشير يتعلمها في ربع ساعة.
7. **"دعم محلي 18 شهر + تحديثات"** — ونحن قريبون.
8. **"سعر مرجعي خاص"** — لأنك أول عميل؛ السعر الرسمي 350$.
