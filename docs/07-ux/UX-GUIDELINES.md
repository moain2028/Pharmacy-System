# إرشادات تجربة المستخدم (UX Guidelines) + Design Tokens

> **المرجع:** R9، SRS §4 (NFR-USE/I18N)، WCAG 2.1 AA، Nielsen Heuristics. تُطبَّق في `packages/ui` و`apps/web`.

---

## 1. المبادئ العشرة (ملزمة)
1. **POS أولاً** — تُفتح بعد الدخول مباشرة؛ أقل من 3 ضغطات لأي مهمة يومية.
2. **لوحة المفاتيح + القارئ تكفي** — الفأرة اختيارية؛ خريطة اختصارات موحدة.
3. **منع الخطأ لا تصحيحه** — لا بيع منتهٍ/سالب؛ تأكيد قبل الترحيل؛ تحذير خصم كبير.
4. **الحالة مرئية دائماً** — شريط ثابت: المستخدم، الوردية، الطابعة، الترخيص، آخر نسخة.
5. **لغة الصيدلي** — المصطلحات من GLOSSARY؛ لا مصطلحات برمجية.
6. **تدرّج التعقيد** — البسيط افتراضي؛ المتقدم خلف "المزيد" أو بصلاحية.
7. **اتساق** — نفس الأماكن/الألوان/الاختصارات في كل شاشة.
8. **RTL أصلي** — logical properties فقط؛ أيقونات اتجاهية تنعكس.
9. **قابلية الوصول** — تباين ≥ 4.5:1، focus مرئي، أهداف ≥ 44px، Tab منطقي.
10. **سرعة ملموسة** — استجابة فورية (optimistic UI للمسودة)، skeletons لا spinners طويلة.

## 2. Design Tokens
```json
{
  "font": { "family": "'IBM Plex Sans Arabic', 'Cairo', system-ui", "sizePos": "16px", "sizeBase": "14px", "sizeTable": "13px" },
  "color": {
    "bg": "#0F172A (dark) / #F8FAFC (light)",
    "surface": "#1E293B / #FFFFFF",
    "primary": "#0EA5E9",
    "success": "#16A34A",
    "warning": "#D97706",
    "danger": "#DC2626",
    "info": "#2563EB",
    "muted": "#64748B"
  },
  "radius": { "sm": "6px", "md": "10px", "lg": "14px" },
  "space": [4, 8, 12, 16, 24, 32],
  "touchTarget": "44px",
  "shadow": "soft, low elevation"
}
```
- **الوضع الافتراضي:** فاتح (إضاءة الصيدليات قوية)؛ داكن اختياري.
- **الأرقام:** Latin افتراضياً؛ خيار عربي-هندي في الإعدادات؛ `Intl.NumberFormat('ar-YE')`.
- **التاريخ:** ميلادي `DD/MM/YYYY` افتراضياً؛ هجري اختياري بجانبه.

## 5. تدفق POS التفصيلي
```
[دخول/PIN] → [وردية مفتوحة؟ لا → فتح وردية (نقد افتتاحي)] → [POS]
POS:
  مسح/بحث → إضافة سطر (وحدة افتراضية، FEFO تلقائي)
  ↑↓ تنقل بين الأسطر · +/− كمية · U وحدة · Del حذف · F8 خصم
  F9 نقدي → [المبلغ المستلم (NumPad) → الباقي] → Enter → ترحيل + طباعة → سطر جديد
  F10 آجل → [اختيار عميل (F3) → تحقق حد] → Enter → ترحيل + طباعة
  F7 تعليق → اسم اختياري → فاتورة جديدة
  F4 مرتجع → [رقم فاتورة/مسح إيصال → اختيار أسطر/كميات → موافقة إن لزم] → ترحيل + طباعة
  F12 إقفال → [عدّ النقد → الفرق → ملاحظة] → Z-report
حالات الخطأ (inline، لا modals مزعجة):
  "منتهي الصلاحية — لا يمكن البيع" (أحمر + بديل مقترح)
  "الكمية غير متوفرة (متاح 3)" 
  "الخصم يتجاوز حدك — اطلب موافقة" (زر موافقة)
  "العميل تجاوز حد الائتمان"
  "الطابعة غير متصلة — حُفظت الفاتورة، أعد الطباعة لاحقاً" (الترحيل لا يفشل بسبب الطابعة)
```

## 6. الطباعة
- قالب HTML/CSS 80mm و58mm قابل للتعديل من الإعدادات (شعار، نص ترويسة/تذييل).
- التحويل: HTML → Canvas/PNG (في Node sidecar عبر `@napi-rs/canvas` أو Playwright headless خفيف) → ESC/POS raster → USB/LAN.
- اختبار طباعة من الإعدادات + كشف تلقائي للطابعات.

## 7. سهولة التعلم
- جولة أولى 5 خطوات؛ وضع تدريب (v1.1)؛ تلميحات اختصارات؛ فيديوهات قصيرة مضمّنة؛ ورقة A4 بجانب الجهاز.
- **قياس:** NFR-USE-001 (≤ 15 دقيقة لأول بيع) يُختبر مع 3 مستخدمين قبل التسليم.

## 8. قائمة تحقق إمكانية الوصول (لكل شاشة)
- [ ] تباين النص ≥ 4.5:1 (axe)
- [ ] كل عنصر تفاعلي قابل للوصول بـ Tab وله focus مرئي
- [ ] أهداف اللمس ≥ 44×44
- [ ] لا معلومة باللون وحده (أيقونة/نص)
- [ ] `aria-live` للرسائل
- [ ] `dir="rtl"` + `lang="ar"`
- [ ] النماذج: تسميات مرتبطة، أخطاء inline واضحة
