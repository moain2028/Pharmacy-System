# ADR-007: المحاسبة — قيد مزدوج Immutable + تقييم بتكلفة الدفعة (Specific Identification)

- **الحالة:** Accepted — 2026-11-03
- **القرار المرتبط:** D-019
- **المتطلبات:** CH-F03, CH-F04, CH-N01, FR-ACC-*
- **البحث:** R6 (Square Books, Modern Treasury, IAS 2)

## السياق
المطلوب "متكامل محاسبياً ورقابياً" لصيدلية صغيرة بلا محاسب متفرغ. التقارير المباشرة من الفواتير (بلا قيود) تنهار عند المرتجعات والديون والمصروفات والعملات.

## القرار
1. دليل حسابات افتراضي عربي للصيدليات (أصول/التزامات/حقوق ملكية/إيرادات/مصروفات) مع حسابات نظامية محمية.
2. **كل حدث مالي = `journal_entry` + `journal_lines`** متوازنة (`Σdebit=Σcredit` كقيد DB)، append-only، العكس بقيد `reversal_of`.
3. **القيود تلقائية** عبر `PostingRules` (جدول في R6 §5) — المستخدم لا يرى "مدين/دائن" في العمل اليومي.
4. **تقييم المخزون و COGS بتكلفة الدفعة الفعلية** (Specific Identification) — الأدق ومتوافق مع IAS 2.
5. **Anglo-Saxon**: COGS يُسجل عند البيع (لا عند الشراء).
6. أرصدة الحسابات projection قابلة لإعادة البناء.
7. `lock_date` لإقفال الفترات (v1.1).
8. العملات (v1.1): كل سطر يحمل مبلغ المعاملة + المبلغ الأساسي + السعر؛ فروق العملة عند التسوية.

## البدائل المرفوضة
- قيد مفرد/تقارير من الفواتير: غير قابل للتدقيق، ينهار مع الحالات الحقيقية.
- متوسط مرجح فقط: أقل دقة مع اختلاف أسعار الدفعات (واقع منصور).
- LIFO: ممنوع في IFRS.

## النتائج
- ✅ أرباح وخسائر وميزانية وذمم صحيحة دائماً.
- ✅ المحاسب الخارجي يجد قيوداً معيارية.
- ⚠️ تعقيد داخلي أعلى — مخفي خلف PostingRules واختبارات شاملة.
