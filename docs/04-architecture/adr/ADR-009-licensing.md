# ADR-009: الترخيص — Ed25519 موقّع + بصمة جهاز + فترة سماح أوفلاين + Feature Flags

- **الحالة:** Accepted — 2026-11-03
- **القرار المرتبط:** D-008, D-002
- **المتطلبات:** CH-F14, CH-F13, FR-LIC-001..006
- **البحث:** R7

## السياق
نسخ البرامج شائع جداً؛ العميل يريد ملكية بدون إنترنت إلزامي؛ نريد باقات.

## القرار
1. توكن `payload.signature` موقّع **Ed25519**؛ المفتاح الخاص على خادمنا فقط؛ العام في التطبيق.
2. Payload: `lic, tenant, mid, plan, features[], seats, iat, exp, grace_days, recheck_days`.
3. **بصمة الجهاز** مرجّحة (MachineGuid/machine-id أساسي + ثانوية) مع تسامح لعامل ثانوي واحد.
4. **تحقق محلي كامل** عند كل تشغيل؛ **تفعيل أوفلاين** عبر تبادل Machine Code؛ إعادة تحقق صامتة عند توفر إنترنت؛ الإلغاء فقط عند رفض صريح.
5. **Ratchet زمني** ضد إرجاع الساعة.
6. **Perpetual:** `exp` = نهاية التحديثات/الدعم؛ البرنامج يستمر. **Subscription:** قراءة فقط بعد السماح. **التصدير متاح دائماً.**
7. `features[]` = مصدر Feature Flags عبر `FeaturePolicy` port + `@RequireFeature` Guard.
8. التحقق في API وTauri (Rust) — ليس الواجهة فقط.
9. خادم ترخيص خاص بنا (Hono/Workers) مع لوحة إدارة بسيطة.

## البدائل المرفوضة
Dongle · أونلاين فقط · HMAC مشترك · خدمات مدفوعة (Keygen/LicenseSpring) الآن.

## النتائج
- ✅ يمنع النسخ العادي؛ لا يعطّل العميل الشرعي؛ يدعم الباقات.
- ⚠️ ليس حماية مطلقة (مقبول).
- ⚠️ تغيير جهاز العميل يحتاج إعادة إصدار (إجراء دعم موثق).
